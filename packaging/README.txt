Quire 0.1.0 (Windows x64)
=========================

双击 Quire.exe 启动。没有文档时显示欢迎页，点击“打开文档”即可。

两种编辑界面
------------
  - 文档界面：DOCX / DOCM / DOTX / RTF / ODT / TXT / MD（纯文本）。分页显示，支持
    正文、表格、图片、编号、页眉页脚、查找替换和右键菜单。
  - 表格界面：XLSX / XLSM / CSV。整张网格，带列标、行号、公式栏和工作表
    标签；支持单元格编辑、矩形选区、复制剪切粘贴、撤销重做、查找、基础公式
    以及 Ctrl+滚轮缩放。可打开 sample.xlsx / sample.csv 试用。
  - XLSX 保存时写回单元格值（不保留公式、样式、合并单元格和图表）；为
    避免覆盖原文件，打开 XLSX 后保存会先询问新的文件名。CSV 直接保存为 CSV。

文档界面快捷键
--------------
  Ctrl+F            查找 / 替换
  Ctrl+K            命令面板
  Ctrl+S            保存（内容不安全回写时会拒绝保存）
  Ctrl+Z / Ctrl+Y   撤销 / 重做
  Ctrl+B / I / U    粗体 / 斜体 / 下划线
  Ctrl+A            全选
  方向键            移动光标；Shift 扩展选区
  Home / End        行首 / 行尾；Ctrl+Home/End 文档首尾
  PageUp / PageDown 上一页 / 下一页
  Ctrl + 滚轮       以画布为中心放大 / 缩小
  鼠标中键拖拽      平移画布
  Ctrl+O / Ctrl+N   打开 / 新建
  F11 / Esc         进入 / 退出专注模式
  插入 -> 表格      新建表格；光标在表格中时，“插入”面板显示表格工具
  Tab / Shift+Tab   在文档表格单元格间移动；最后一格 Tab 自动加行
  右键              撤销、复制、剪切、删除、插入表格/图片、表格行列操作

表格界面快捷键
--------------
  方向键            移动当前单元格
  Shift + 方向键    扩展矩形选区；也可以直接拖拽选择
  Enter / Tab       下移 / 右移；Shift+Tab 左移
  F2 或双击         编辑单元格；也可以点“编辑”按钮
  直接输入          覆盖当前单元格内容
  Delete/Backspace  清空当前选区
  Ctrl+C / X / V    复制 / 剪切 / 粘贴（支持矩形选区）
  Ctrl+Z / Ctrl+Y   撤销 / 重做
  Ctrl+F            查找单元格内容
  Ctrl + 滚轮       放大 / 缩小表格；Ctrl+0 恢复 100%
  Ctrl+S            保存（XLSX 会询问新文件名）
  Ctrl+O            打开文件
  右键              撤销、复制、剪切、编辑、清空、插入/删除行列、查找
  底部工作表标签    切换工作表

系统要求
--------
  - Windows 10/11 x64
  - 可用的显卡驱动（使用 wgpu；无 GPU 时可能回退到系统软件适配器）
  - 不联网、不登录、无云同步、无广告、无遥测

注意
----
  - 可执行文件未做代码签名；SmartScreen 提示时选择“更多信息”->“仍要运行”。
  - DOCX 表格单元格可以直接点击编辑；页眉页脚和编号段落仍不能点击编辑。
  - 跨表格单元格选择只清除文字，不合并单元格。
  - 表格界面只支持基础公式（四则运算、SUM/AVERAGE/MIN/MAX/COUNT）；没有
    完整公式库、样式、合并单元格、图表和冻结窗格。保存时只写计算值。
  - 旧版 .doc / .xls 和 PDF 不能直接导入；ODT 可以导入和导出（带编号列表的
    文档导出 ODT 会被拒绝，而不是丢失编号）。
  - 文档保存走保真检查：遇到域、批注、修订、浮动图形等未建模内容会拒绝保存。
  - 文档目前仍只写第一个节；表格行跨页、自动列宽等边界见项目 README。
